 Blog de Normalização SQL

Um blog educativo desenvolvido para apresentar os principais conceitos de normalização de bancos de dados relacionais, explicando como organizar tabelas, reduzir redundâncias e garantir a integridade dos dados.

O projeto tem como objetivo facilitar o aprendizado sobre as formas normais e sua importância no desenvolvimento de bancos de dados eficientes e bem estruturados.

Objetivos do projeto

Compreender os conceitos fundamentais da normalização de bancos de dados.

Conhecer as diferentes formas normais e suas aplicações.

Entender como a normalização ajuda a reduzir a redundância de informações.

Identificar problemas de organização e dependências em tabelas relacionais.

Apresentar conteúdos técnicos de forma clara e acessível.

Conteúdos abordados

O blog tem como foco os conceitos de normalização de bancos de dados, incluindo:

Primeira Forma Normal (1FN): organização dos dados em valores atômicos, sem grupos repetitivos.

Segunda Forma Normal (2FN): eliminação de dependências parciais em relação às chaves candidatas.

Terceira Forma Normal (3FN): tratamento de dependências transitivas inadequadas.

Forma Normal de Boyce-Codd (BCNF): critérios mais rigorosos para dependências funcionais.

Quarta Forma Normal (4FN): tratamento de dependências multivaloradas.

Quinta Forma Normal (5FN): análise de dependências de junção.

O conteúdo busca demonstrar como esses conceitos contribuem para a construção de estruturas de dados mais consistentes.

Tecnologias utilizadas

HTML5: estruturação do conteúdo e das páginas.

CSS3: estilização e apresentação visual do blog.

SQL e modelagem relacional: conceitos abordados nos conteúdos educacionais.

Como executar

Como o projeto utiliza HTML e CSS, você pode acessá-lo localmente sem precisar configurar um servidor de banco de dados.

Clone o repositório:

git clone https://github.com/ARES55Marinho/blog_Nomaliza-o-SQL.git

Entre na pasta do projeto:

cd blog_Nomaliza-o-SQL

Abra o arquivo index.html no navegador.

 Finalidade acadêmica

Este projeto foi desenvolvido com finalidade educacional, contribuindo para o estudo de bancos de dados relacionais, dependências funcionais e técnicas de normalização.

A proposta é transformar conceitos teóricos em um material de consulta que facilite a compreensão e a aplicação dos fundamentos de modelagem de dados.
